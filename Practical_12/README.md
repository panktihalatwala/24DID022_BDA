# Practical 12: Customer Sales Dashboard Using Interactive Analytics

## Objective
To develop an interactive sales dashboard that helps management analyze sales performance across products, regions, and customer segments.

## Tools and Technologies
- Python
- Pandas
- Plotly
- Streamlit
- Sample Superstore dataset

## Dashboard Features
- Total Sales, Total Profit, Orders, and Customers KPI cards
- Region, Category, and Order Date filters
- Sales by Category
- Monthly Sales Trend
- Profit by Region
- Customer Segment Analysis
- Product Profitability Analysis
- Quarterly Sales Performance
- Filtered Transaction Table
- CSV Download

## Installation
Install the required libraries:

    pip install -r requirements.txt

## Run the Dashboard
Run the following command from this directory:

    streamlit run dashboard.py
