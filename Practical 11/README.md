# Practical 11: Distributed SMS Spam Classification

## Objective
SMS spam classification using Apache Spark, TF-IDF, Logistic Regression, model evaluation, and distributed gradient-descent experiments.

## Technologies
- Python
- Apache Spark
- PySpark MLlib
- Hadoop HDFS

## Dataset
UCI SMS Spam Collection:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

## Implementation
- prepare_sms.py: Prepares the SMS dataset.
- practical11.py: Main classification and evaluation program.
- optimization_comparison.py: Compares full-batch and mini-batch gradient descent.
- scaling_experiment.py: Tests training time and accuracy at increasing dataset sizes.

Execution results should be added after the programs run successfully.
